Environment in which every result in this repository was produced.

R version 4.6.1 (2026-06-24 ucrt)
Platform: x86_64-w64-mingw32/x64 (64-bit)

Required packages
  partykit    1.3.0     <- version matters, see README "Environment"
  MASS
  matrixcalc

partykit is pulled in for mob(); MASS for ginv() and mvrnorm(); matrixcalc for
vec(). Nothing else is needed: the GEE family step and working-precision
helpers are implemented in R/era_gee_fixed.R rather than taken from another
package.

The 1,000-replication simulation was run on 32 workers via parallel::makeCluster
and took 84 minutes.
